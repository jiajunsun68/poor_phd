# phd穷哥们儿到处蹭教程

# 1：省个todesk会员

**TL;DR**

我们phd哥们儿可以通过windows内置的mstsc功能，方便的免费远程连接工位电脑，而且效果远比todesk会员好。方法参考[mstsc远程链接教程](https://github.com/jiajunsun68/ssh-into-wsl/blob/main/%E8%B9%AD%E6%A0%A1%E5%9B%AD%E7%BD%91%E8%BF%9C%E7%A8%8B%E6%8E%A7%E5%88%B6%E6%A1%8C%E9%9D%A2.md)

**motivation**

随着phd哥们儿日益走火入魔，稳定好用的电脑远程控制软件正在成为他们的需求。目前市面上有很多远程办公软件，例如todesk和向日葵，让phd哥们儿能够随时随地监控工位电脑上的实验。然而，市面上的远程链接软件各有各自的缺点，例如，todesk的会员很贵，对于免费版，todesk用户则随时都有可能断开链接的风险，这给phd哥们儿带来了很强的不安全感。向日葵是一个免费链接软件，然而，众所周知的是，向日葵的免费版画质很差，很多时候很难看得清被控制电脑上的字。moreover，他们还有一个共同的问题，他们解决问题的方式是通过截屏或录屏的方式来解决远程控制这一问题，这就说明，用户的控制端的展示范围由被控端的电脑尺寸决定，如果被控端的电脑使用的是带鱼屏，我们的游戏电脑远程控制时，将大部分展示为黑色边框，这更加剧了画质差的缺点。解决远程链接不稳定，不清晰越来越成为phd哥们儿们的需求。

于是我们头脑风暴了一下，我们发现这些现象：1. 会议室里的大显示屏，我们只需要连上相同的wifi，就能流畅的把电脑内容投影到大显示屏上，这说明局域网内的相互通信是非常畅通的。2. 实验室的服务器，我们只能通过内网穿透来进行ssh链接，这说明整个校园网是一个较大的局域网。基于以上两个发现，我们不难推导出：只要我们内网穿透进校园网，把工位电脑投影到宿舍电脑是一件非常容易解决的事情。

于是，为了解决以上问题，我们准备大干一场，然后我们发现windows给这一功能留了后门……
